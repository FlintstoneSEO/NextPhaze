# NextPhaze content guide

Welcome to the NextPhaze website editor.

## Quick links

- [Pages](cloudcannon:collections/pages) — edit the homepage, overview pages, coach page, booking page, and policies.
- [Training formats](cloudcannon:collections/services) — edit group and one-on-one training details.
- [Training focuses](cloudcannon:collections/focus_areas) — edit speed, agility, and receiver-development pages.
- [Shared content](cloudcannon:collections/data) — edit navigation, footer copy, training-option summaries, and development-focus summaries.

Open an existing page in the Visual Editor to edit text and images directly in the preview. Page sections can be added, removed, and reordered. The Data Editor shows every field in one place.

New page-builder pages initially preview using the homepage until CloudCannon saves and rebuilds their own URL. New policy pages initially preview using the Privacy page and open in the Content Editor for writing.

Training formats and focuses use a consistent layout. Shared training options, focus areas, navigation, and footer content can appear on several pages, so review those changes before publishing.

The Square booking address and production website address are deployment settings and are not edited here.
